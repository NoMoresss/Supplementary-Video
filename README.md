# Supplementary Videos

This repository provides supplementary videos for the MATLAB-SUMO
co-simulation validation presented in the manuscript.

## Video S1: MATLAB-SUMO Co-Simulation

This video demonstrates the collision-free formation behavior of the
five-vehicle system in the MATLAB-SUMO co-simulation environment.

The proposed controller is implemented in MATLAB, while SUMO provides
the virtual traffic environment and vehicle visualization through TraCI.
